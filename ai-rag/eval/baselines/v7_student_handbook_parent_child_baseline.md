# 学生手册 RAG 基线 v7（父子检索与回答复核）

- 基线日期：2026-09-16
- 上一版基线：v6（回答约束，100.0%）
- 知识库：714 个结构化分块，714 个分块带父级元数据，667 个父级
- 回答模型：`deepseek-flash`
- 评判模型：`deepseek-chat`
- 精排模型：`qwen3.7-text-rerank`

## 新增能力

- 子块负责 BM25、向量检索和 Rerank
- 按 `parent_id` 恢复完整条款、表格或记录组
- 父子分组优先结构、结构不足时按固定窗口兜底
- Query Rewrite 后使用自包含问题参与 Rerank
- 回答完整性复核，必要时使用同一批证据补全一次
- 登录用户由 Spring Boot 校验会话归属并生成 `thread_id`
- 游客使用 HMAC 签名 Cookie，并按本地会话隔离短期记忆
- Spring Boot 到 Python 使用内部 HMAC 时间戳签名
- 短期记忆使用 revision 乐观锁和后台 TTL 清理
