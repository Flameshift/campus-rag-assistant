# AI 咨询助手使用说明

AI 咨询助手是一款基于 RAG 与 LangChain 构建的智能问答系统，可以接入企业知识库、产品文档与个人资料，根据检索到的内容生成带来源的答案。

## 主要功能

- 文档问答：支持上传 PDF、Word、Markdown、TXT 等格式，内容写入向量知识库。
- 联网搜索：开启后可以检索实时信息，回答更及时。
- 深度思考：适合复杂分析、决策推演与长文本理解。
- 长上下文：支持多轮对话，保持咨询思路连贯。

## 使用方式

1. 在网页端进入“开始对话”页面。
2. 在输入框输入问题，Enter 发送。
3. 点击上传按钮把资料加入知识库，之后提问会自动检索相关资料。

## 服务接口

- GET /health：健康检查
- POST /api/upload：上传资料
- POST /api/chat：发起问答

## 演示模式

未配置 API Key 时服务会以演示模式运行，检索仍可用，但回答使用本地模拟内容；配置 Key 后自动切换到真实 RAG 问答。
