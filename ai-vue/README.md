# AI 咨询助手（ai-vue）

基于 Vue 3 + Vite 构建的前端项目，包含类似 DeepSeek 官网的落地首页，以及保留的 AI 咨询对话界面。

## 页面路由

- `/`：落地首页，风格参考 DeepSeek 官网，点击“开始对话”跳转到对话页
- `/chat`：AI 咨询对话页，包含侧边栏、欢迎区、输入区与消息列表

## 页面结构

- 左侧边栏：新建对话、搜索对话、最近对话列表、删除对话、用户信息区
- 对话首页：咨询分类建议卡片、快捷提问
- 对话区：消息气泡、AI 思考中状态
- 输入区：上传附件、上传图片、语音输入、深度思考、联网搜索、发送

## 当前状态

页面交互已完成基础演示：首页跳转、新建对话、切换历史对话、删除对话、建议卡片提问、发送消息与模拟回复。各按钮的具体业务功能待接入后端后实现。

## 运行

```sh
npm install
npm run dev
```

## 构建

```sh
npm run build
```

## 后端接口联调

聊天页会调用 `POST /api/chat`，上传页会调用 `POST /api/upload`。默认后端地址为
`http://127.0.0.1:8000`，可通过 `VITE_API_BASE_URL` 覆盖（参考 `.env.example`）。
后端不可用时聊天页自动降级为模拟回复。
